**Resumo**-

Resolução de um exercício que envolve a escrita de um código para, através dos objetivos demarcados pelo professor, criar um jogo.

O jogo "Corrida para 100" tinha como objetivos; a máquina e o utilizador jogavam alternadamente, adicionando números aleatórios entre 1 e 10, tentando chegar ao valor total de 100 sem o ultrapassar. Quando um dos jogadores atingia exatamente 100, o programa dava print da mensagem de vitória e terminava.
