**Resumo**-

Esta aplicação em Python foi desenvolvida para a gestão e análise de dados meteorológicos através de um menu interativo de consola. Os dados são estruturados numa lista de tuplos, onde cada registo armazena a data (ano, mês e dia em formato numérico para garantir a ordenação cronológica correta), as temperaturas mínima e máxima, e o valor da precipitação.
O programa integra funcionalidades essenciais, além de várias operações analíticas e estatísticas. Permite calcular médias térmicas diárias, amplitudes térmicas, encontrar a temperatura mínima absoluta, identificar dias com precipitação máxima ou acima de um limite definido pelo utilizador, calcular períodos consecutivos de baixa precipitação e gerar gráficos descritivos em formato de texto.
