**Resumo**-

Para este TPC5 tivemos como objetivo utilizar as aprendizagens das últimas aulas, criando uma aplicação para gestão de alunos.
O programa permite criar turmas dinamicamente, registar alunos com identificadores, consultar registos por ID e garantir a persistência da informação através da gravação e leitura de ficheiros de texto.
Para concretizar este trabalho, utilizei funções, dicionários e listas para organizar eficientemente os dados.
