**Resumo**-

Resolução de um exercício que envolve a escrita de um código para, através dos objetivos demarcados pelo professor, criar um jogo.

O jogo "Adivinha o número!" tinha como objetivos; A máquina escolher aleatoriamente um número entre 0 e 100 e pedir o nosso primeiro input com a frase "Diga um valor"; Enquanto o valor inserido fosse maior ou menor que o escolhido, a máquina teria que voltar a pedir novo input; Quando os valores fossem iguais, o programa faria print da mensagem "Acertou em X tentativas" e terminava.
