**Resumo**-

Este projeto em Python foi desenvolvido para a resolução de diversos exercícios práticos de programação, estruturando-se em três domínios fundamentais. No TPC1, aplicaram-se compreensões de listas na filtragem de dados, processamento de texto e manipulação de sequências. No TPC2, foram implementados algoritmos e funções de lógica matemática e processamento de strings, focados em cálculos otimizados e pesquisa de padrões. Por fim, no TPC3, desenvolveu-se um sistema de gestão para uma rede social (MyFaceBook), estruturado com listas e dicionários, que integra operações essenciais de registo, gestão dinâmica de identificadores, listagem alfabética de autores, distribuição estatística e análise de interações entre utilizadores.
